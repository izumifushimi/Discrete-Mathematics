① 图同构 p.91

定义（无向图同构） (1) 无向图 \(G_1=\langle V_1,E_1\rangle\)，\(G_2=\langle V_2,E_2\rangle\)。若存在双射 \(f:V_1\to V_2\)，满足 \(\forall u,v\in V_1\)， \[ (u,v)\in E_1\longleftrightarrow (f(u),f(v))\in E_2 \] 则 \(G_1\) 与 \(G_2\) 同构，记作 \(G_1\cong G_2\)。（原笔记在 \(f(u)\)、\(f(v)\) 下划线。）
定义（有向图同构） (2) 有向图 \(D_1=\langle V_1,E_1\rangle\)，\(D_2=\langle V_2,E_2\rangle\)。若存在一个双射 \(f:V_1\to V_2\)，满足 \(\forall u,v\in V_1\)， \[ \langle u,v\rangle\in E_1\longleftrightarrow \langle f(u),f(v)\rangle\in E_2 \] \(\therefore\ D_1\cong D_2\)。
校订说明（p.91） 原式：\(\langle u,v\rangle\in E_1\longleftrightarrow (f(u),f(v))\in E_2\)；正确式：\(\langle u,v\rangle\in E_1\longleftrightarrow \langle f(u),f(v)\rangle\in E_2\)；原因：有向图的边是有序对，右边也应写尖括号，表示方向保持。
例（同构的两种画法） p.91–92
补充讲解 同构只看顶点间的邻接关系，与画法无关。判断不同构时常用必要条件：阶数、边数、度数列、圈的长度等不变量；有一个不同即不同构，但这些都相同也不能断定同构。

(3) r 部图（有 r 部分）

定义（r 部图） \(G=\langle V,E\rangle\)，\(V=V_1\cup V_2\cup\cdots\cup V_r\)，\(V_i\cap V_j=\emptyset\ (i\ne j)\)，\(E\subseteq\bigcup(V_i\,\&\,V_j)\)。（原笔记在 \(\bigcup(V_i\&V_j)\) 下画波浪线。）
补充讲解 \(V_i\&V_j\) 表示 \(V_i\) 与 \(V_j\) 的无序积 \(\{(u,v)\mid u\in V_i,v\in V_j\}\)，并集取遍 \(i\ne j\)（即 \(i\lt j\)）。意思是每条边的两个端点在不同部分，同一部分内部无边。
待核对（p.92，位置：页面下部 3 部图，Ⅰ 与 Ⅲ 之间的交叉线） 可辨认部分：Ⅰ、Ⅱ 间两条边，Ⅱ 到 Ⅲ 一条竖边，Ⅰ 到 Ⅲ 有四条左右交叉的斜线；无法辨认：交叉斜线在 Ⅲ 内的确切端点（上列边表按最可能的读法给出）。

③ 子图、生成子图、导出子图 p.93–94

定义（子图） \(G=\langle V,E\rangle\)，\(G'=\langle V',E'\rangle\)， \[ G'\subseteq G\iff V'\subseteq V\land E'\subseteq E \] （原笔记在 \(V'\subseteq V\)、\(E'\subseteq E\) 下划红线。）
定义（真子图） \[ G'\subset G\iff G'\subseteq G\land(V'\subset V\ \text{或}\ E'\subset E) \]
笔记边注 原笔记真子图式中左侧写作 \(G'_1\subseteq G\) 样的字迹，“或”字写在 \(\lor\) 符号下方作说明，即括号内写作 \(V'\subset V\lor E'\subset E\)。
定义（生成子图） \(G'\) 为 \(G\) 的生成子图 \(\iff G'\subseteq G\land V'=V\)。
定义（导出子图） \(G=\langle V,E\rangle\)，导出方式分“点”和“边”两种（原笔记画分叉箭头指向“点”“边”）。

点导出：若 \(V_1\subset V\)，\(E_1=E\cap(V_1\&V_1)\)，则 \(G[V_1]=\langle V_1,E_1\rangle\)，称为由 \(V_1\) 导出的子图。（原笔记在 \(V_1\) 下划线，\(E\) 下画双线，\(\&\) 下加三角记号。）

边导出：若 \(\emptyset\ne E_1\subset E\)，\(V_1=\{v\mid v\ \text{与}\ E_1\ \text{中的边关联}\}\)，则 \(G[E_1]=\langle V_1,E_1\rangle\)。

例 p.94
补充讲解 点导出子图“点定边”：选定顶点后，原图中两端都在 \(V_1\) 里的边必须全部保留。边导出子图“边定点”：选定边后，顶点只取这些边的端点。两者一般不同，例如若 \(V_1\) 中两点在原图另有一条边而未选入 \(E_1\)，\(G[V_1]\) 会多出这条边。

定义（自补图） \(G\cong\overline{G}\)。 p.95
例
补充讲解 映射 \(a\mapsto b,\ b\mapsto d,\ c\mapsto a,\ d\mapsto c\) 把 \(G\) 的边 \(ab,bc,cd\) 映为 \(bd,da,ac\)，正是 \(\overline G\) 的边。自补图的边数为 \(\frac{n(n-1)}{4}\)，所以 \(n\equiv 0\) 或 \(1\pmod 4\)。

⑤ 图的运算 p.95–96

1) 删除（delete）

定义（删除） \[ \begin{aligned} G-e&=\langle V,E-\{e\}\rangle &&\text{删边 } e\\ G-E'&=\langle V,E-E'\rangle &&\text{删边集 } E'\\ G-v&=\langle V-\{v\},E-I_G(v)\rangle &&\text{删点 } v\text{，与其相关联的边}\\ G-V'&=\langle V-V',E-I_G(V')\rangle &&\text{同理} \end{aligned} \] （原笔记用大括号把删点 \(G-v\) 与删点集 \(G-V'\) 两行括在一起，并在 \(\{v\}\) 下画双线。）
例（删点）

2) 收缩、加新边

定义（收缩） \(G\backslash e\)：\(e=(u,v)\)，把 \(u,v\) 合并为一个顶点，删去 \(e\)，原来与 \(u\) 或 \(v\) 关联的边改为与新顶点关联。
定义（加新边） p.96 \[ G\cup(u,v)=\langle V,E\cup\{(u,v)\}\rangle \] 也可以记为 \(G+(u,v)\)。（右侧小图：顶点 \(u\) 到 \(v\) 画一条弧线，表示新加的边。）

⑥ 不交 p.96

定义（不交、边不交） \(G_1=\langle V_1,E_1\rangle\)，\(G_2=\langle V_2,E_2\rangle\)。 \[ \begin{aligned} G_1\text{ 与 }G_2\text{ 不交}&\iff V_1\cap V_2=\emptyset\\ G_1\text{ 与 }G_2\text{ 边不交}&\iff E_1\cap E_2=\emptyset \end{aligned} \]
易错提醒 不交一定边不交；边不交不一定不交（可以共用顶点）。

⑦ 并图、交图、差图、环和 p.96

定义 \(G_1=\langle V_1,E_1\rangle\)，\(G_2=\langle V_2,E_2\rangle\)，都无孤立点。 \[ \begin{aligned} \text{并：}G_1\cup G_2&=\langle V(E_1\cup E_2),\ E_1\cup E_2\rangle\\ \text{交：}G_1\cap G_2&=\langle V(E_1\cap E_2),\ E_1\cap E_2\rangle\\ \text{差：}G_1-G_2&=\langle V(E_1-E_2),\ E_1-E_2\rangle\\ \text{环和：}G_1\oplus G_2&=\langle V(E_1\oplus E_2),\ E_1\oplus E_2\rangle \end{aligned} \] （原笔记用红框框出右侧四个边集，下加三角记号。）
补充讲解 \(V(E')\) 表示边集 \(E'\) 中所有边的端点构成的集合，所以这样定义的运算结果没有孤立点，这正是原笔记“都无孤立点”的含义。

⑧ 联图 p.97

定义（联图） \(G_1,G_2\) 不交，\(G_1=\langle V_1,E_1\rangle\)，\(G_2=\langle V_2,E_2\rangle\)， \[ G_1+G_2=\langle V_1\cup V_2,\ E_1\cup E_2\cup(V_1\&V_2)\rangle \] （原笔记在 \(V_1\cup V_2\) 下划线，\(E_1\)、\(E_2\) 下画双线，\((V_1\&V_2)\) 下画双线。）
例
补充讲解 \(|E(G_1+G_2)|=|E_1|+|E_2|+|V_1|\,|V_2|\)。例如 \(K_m+K_n=K_{m+n}\)，\(\overline{K_m}+\overline{K_n}=K_{m,n}\)（\(\overline{K_m}\) 为 \(m\) 个孤立点）。
